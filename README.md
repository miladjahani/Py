# شبیه‌ساز مهندسی مدار استخراج با حلال و الکترووینینگ مس (SimSXEWCu v7.0)

این بسته نرم‌افزاری بر پایه مدل متالورژیکی **SimSXEWCu Partial Version 7.0** (توسعه‌یافته توسط جوزف کافومبیلا) بازنویسی و پیاده‌سازی شده است. نرم‌افزار امکان تحلیل دقیق موازنه جرم، محاسبات تعادل ترمودینامیکی استخراج مس و آهن با اکسترکتنت LIX 984N، طراحی سلول‌های الکترووینینگ (EW)، تخمین مصارف مواد شیمیایی و شبیه‌سازی مراحل شستشو و اسکرابینگ آهن را در کلیه آرایش‌های فرآیندی فراهم می‌سازد.

## ۲. قابلیت‌ها و آرایش‌های شبیه‌سازی‌شده (Configurations)

* **مدار A1 (پایه بدون شستشو):** مدل‌های ۲Ex-۱S و ۳Ex-۱S و ExPx-۱S با خروج بلید به مدار لیچ.
* **مدار A2 (پایه با سیرکولاسیون):** بازگردانی بلید الکترووینینگ (EWB) به مرحله استخراج E1 جهت ارتقای بازیابی مس به بیش از ۹۱٪.
* **مدار B1 و B2 (شستشو در لندر E1):** شستشوی منگنز و قطرات فاز آبی در لندر فاز آلی E1 (حذف کامل پرمنگنات از الکترولیت).
* **مدار C1 و C2 (شستشوی اختصاصی با آب خام):** میکسر-ستلر مجزا برای شستشوی منگنز و آهن ($O/A = 50$).
* **مدار D1 و D2 (اسکرابینگ با آب اسیدی):** حذف گزینشی آهن از فاز آلی با راندمان ۵۰٪ و افزایش چشمگیر نسبت Cu/Fe فاز آلی به بالای ۹۵۰.
* **مدار E1 و E2 (اسکرابینگ با بلید رقیق EW):** بهینه‌ترین پیکربندی متالورژیکی؛ اسکرابینگ ۵۶.۶٪ آهن با استفاده از اسید موجود در بلید الکترولیت، افزایش نسبت Cu/Fe آلی به بیش از ۱۰۹۰ و کاهش ۴۰ درصدی دبی بلید.

## ۳. نحوه اجرا و استفاده

### الف) اجرای خط فرمان (CLI)
برای اجرای سریع محاسبات از ترمینال (سازگار با لینوکس، سرور و محیط Termux اندروید):

```bash
# اجرای مدار پایه ۲Ex-۱S با دبی ۱۰۰۰ مترمکعب و عیار ۲.۵ گرم بر لیتر مس
python3 cli.py --config A1_2Ex1S --flow 1000 --cu 2.5

# شبیه‌سازی پیشرفته مدار E1 با خروجی ساختاریافته JSON
python3 cli.py --config E1_2Ex1S --json

# شبیه‌سازی مدار شستشوی اسیدی با دبی دلخواه
python3 cli.py --config D1_2Ex1S --flow 800 --cu 3.2 --fe3 0.6 --mn 3.5
```

### ب) اجرای داشبورد تعاملی تحت وب
فایل `web/index.html` به صورت کاملاً مستقل و سبک پیاده‌سازی شده و نیازی به سرور خارجی یا نصب کتابخانه ندارد:
1. می‌توانید مستقیماً فایل `web/index.html` را در هر مرورگری باز کنید.
2. یا با استفاده از وب‌سرور داخلی پایتون آن را اجرا نمایید:
```bash
python3 -m http.server 8080 --directory web
```
سپس آدرس `http://localhost:8080` را در مرورگر مشاهده فرمایید.

### ج) اجرای آزمون‌های واحد (Unit Tests)
برای اعتبارسنجی تمام محاسبات در برابر بنچ‌مارک‌های متالورژیکی:
```bash
python3 -m unittest discover -s tests -v
```
